# Manuscript reproduction

[Documentation index](README.md) · [Main README](../README.md)

The package defaults prioritize a stable user interface. Historical manuscript
settings—such as specialized initializations, priors, masks, loop ordering, and
effective multinomial counts—are intentionally absent from the installed
package. They are provided in the companion
[`efsc-paper-reproduction`](https://github.com/blei-lab/efsc-paper-reproduction)
repository.
